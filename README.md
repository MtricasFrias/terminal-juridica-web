# Terminal Jurídica · SETP Ibagué (página)

Página de la Terminal Jurídica del SETP alojada en GitHub Pages. Los datos y los recordatorios viven en Google Apps Script y una hoja de cálculo de Google; esta página solo se comunica con ese servidor y no usa cuentas de Google, por lo que abre igual con una o varias cuentas abiertas en el navegador.

El código completo del sistema está en un repositorio privado.
